# Piece sets

Drop piece sets here and they show up in the main menu under **Pieces**:

- a `.glb` / `.gltf` file with one object per piece, named `Pawn`, `Knight`,
  `Bishop`, `Rook`, `Queen` and `King`, or
- a `PieceSet` resource (`.tres`) created in the Godot editor.

See the "Custom piece sets" section of the main README for details.
